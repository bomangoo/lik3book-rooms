# ❄ 겨울 서재 · lik3book rooms

🔗 https://lik3book.p-e.kr

눈 내리는 겨울 밤, 벽난로가 타닥타닥 타는 산방 서재에 모여 **책을 읽거나 조용히 사색하는** 2D 온라인 공간입니다.
바람의 나라 같은 2등신 픽셀 캐릭터로 입장하고, 한 방(호실)에 최대 5명이 함께 머물 수 있습니다.

## 주요 기능

- **캐릭터 선택 & 이름 짓기**: 선비 도령, 댕기 낭자, 동자승, 아기 호랑이, 눈토끼, 털모자 아이 (6종, 코드로 그린 픽셀 아트)
- **세션 스토리지 저장**: 캐릭터·이름·책갈피는 `sessionStorage`에 저장되어 같은 탭으로 다시 오면 바로 입장합니다.
- **실시간 함께하기**: WebSocket으로 위치·자세·말풍선·감정 표현을 주고받고, 방이 차면 다음 호실로 안내합니다.
- **포근한 자리들**: 정면을 보는 창가 벤치·흔들의자·빈백·독서 의자, 서로 마주 보는 벽난로 앞 안락의자, 벽난로를 바라보는 소파
- **책 읽기**: 라이크북 책장에서 책을 골라 **한 장씩 넘기며** 읽습니다. PC는 두 쪽 펼침, 모바일은 한 쪽 보기.
  넘기는 효과음, 스와이프/탭 넘기기, 읽던 곳을 기억하는 **책갈피**(세션 스토리지)
- **서재지기의 책상**: 서재지기가 올린 일기·이야기를 주제별로 모아 공책처럼 읽습니다.
- **사색하기**: 호흡 가이드와 생각거리
- **소리**: AI로 만든 잔잔한 피아노 배경음악 + 벽난로 장작 소리 (상단 ♪ 버튼)

## 조작법 (키보드는 6개 키면 충분해요)

| 키 | 하는 일 |
| --- | --- |
| `←` `↑` `↓` `→` | 걷기 · 메뉴/책 고르기 · 책장 넘기기 |
| `Space` | 앞에 있는 의자에 앉기, 책장·책상·벽난로 살펴보기 · 아무것도 없거나 앉아 있으면 **행동 메뉴**(책 읽기 · 사색 · 말하기 · 감정 표현 · 서재지기의 글 · 일어나기) · 선택 |
| `Esc` | 일어나기 · 창 닫기 |

`Enter`는 `Space`와 같고, `WASD`도 방향키처럼 쓸 수 있습니다. 모바일/마우스는 바닥과 가구를 누르면 됩니다.

## 책과 서재지기 글 올리기

DB 없이 **이 저장소의 `content/` 폴더에 마크다운 파일을 올리면** 됩니다. GitHub 웹에서 파일을 추가하고 커밋하면 `main`에 반영되면서 자동으로 다시 배포돼요.
자세한 형식은 [`content/README.md`](content/README.md)를 보세요.

```
content/
  books/<책아이디>/book.md      ← 책 정보(제목·표지·면지) + 본문
  books/<책아이디>/*.jpg        ← 표지, 면지, 삽화
  journal/2026-11-11-open.md    ← 서재지기의 글 (category 로 주제 구분)
```

## 시작하기

```bash
npm install
npm run dev        # 웹(vite, :5173) + 실시간 서버(:8787) 동시 실행
```

### 배포

- **맥미니로 실시간 서버 (무료, 추천)**: [`deploy/macmini/README.md`](deploy/macmini/README.md) 를 따라 설치 스크립트 한 번이면 됩니다. Tailscale Funnel 로 공개하고, 나온 주소를 `WS_URL` 로 등록하면 GitHub Pages 화면에서 5명이 함께 머물 수 있어요.
- **Node 서버(직접 호스팅)**: `npm run build && npm start` — 정적 파일과 WebSocket(`/ws`)을 한 서버에서 제공합니다. `ALLOWED_ORIGINS` 로 접속 가능한 사이트를 제한할 수 있어요.
- **GitHub Pages**: `main`에 푸시하면 `.github/workflows/deploy-pages.yml`이 배포합니다. 저장소 **Settings → Pages → Source = GitHub Actions** 가 필요합니다.
  Pages에는 실시간 서버가 없어 **혼자 모드**로 동작하며, 외부 서버를 띄운 뒤 저장소 변수 `WS_URL`(예: `wss://my-server/ws`)을 넣으면 함께하기가 켜집니다.
